# adfs-ignition-sso-docs

Public, sanitized copy of the guide **Windows SSO for Ignition Perspective** (AD FS + OpenID Connect + Kerberos).

**Read it online:** https://huamchengboon.github.io/adfs-ignition-sso-docs/

The page is a single self-contained HTML file (`index.html`): build steps, verification checklist, searchable troubleshooting, production notes and a rebuild script.

> All host names, IP addresses, the domain and certificate thumbprints in this copy are **placeholders** (`example.local`, `DC01`, `10.0.0.10`, ...). No credentials, keys or secrets are included. The original values live in a private repository.
